## Project Overview

This is a Go JSON library benchmark suite comparing performance of:
- `encoding/json` (stdlib)
- `goccy/go-json`
- `json-iterator/go`
- `mailru/easyjson` (code generation based)
- `tidwall/pretty` (formatting only)

## Common Commands

```bash
# Full workflow: generate code → run benchmarks → generate README report
make all

# Generate easyjson code (required before running benchmarks)
make generate

# Run benchmarks (outputs to benchmark_results.txt)
make benchmark

# Quick single-run benchmark without report
make quick-benchmark

# Generate README.md from benchmark results
make report

# Run single benchmark
go test -bench=BenchmarkEncode_Small_EasyJSON -benchmem ./benchmark/...

# Verify generated code is up to date
make verify
```

## Architecture

**Test Data** (`internal/testdata/`):
- `types.go`: Defines `SmallStruct` (~10 fields) and `LargeStruct` (~50 fields with nested structs, arrays, maps)
- `types_easyjson.go`: Auto-generated by easyjson, committed to repo
- `generator.go`: Creates reproducible test data with fixed seeds

**Benchmarks** (`benchmark/`):
- `encode_test.go`: Marshal benchmarks for all 4 JSON libraries
- `decode_test.go`: Unmarshal benchmarks for all 4 JSON libraries
- `pretty_test.go`: JSON formatting benchmarks (tidwall/pretty vs json.Indent)
- Shared test data initialized in `encode_test.go` via package-level `init()`

**Report Generator** (`cmd/report/`):
- Parses `go test -bench` output using regex
- Generates Markdown tables with speedup calculations and ASCII bar charts

## Benchmark Naming Convention

Benchmarks follow pattern: `Benchmark{Operation}_{Size}_{Library}`
- Operation: `Encode`, `Decode`, `Pretty`, `Ugly`
- Size: `Small`, `Large`
- Library: `StdLib`, `GoJSON`, `JSONIterator`, `EasyJSON`, `TidwallPretty`, `TidwallUgly`

## Code Generation

EasyJSON requires code generation. After modifying `internal/testdata/types.go`:
```bash
make generate  # or: easyjson -all internal/testdata/types.go
```

The generated `types_easyjson.go` is committed to the repository.
